## 🩺 연구 배경
- 현대 사회에서 운동 부족과 잘못된 습관은 **비만, 관절 질환, 심혈관 질환** 등 다양한 문제의 원인.  
- 러닝은 접근성이 높지만, **맞춤형 관리가 부족할 경우 부상 위험**이 큼.  
- 기존 러닝 앱(NRC, Strava 등)은 기록·코스 공유에 강점이 있으나,  
  **건강 관리(부상 예방, 스트레칭, 맞춤 운동 처방)** 측면은 부족함.  

---

## 🔍 연구 필요성
- 헬스케어 + IT 융합을 통해 **개인 맞춤형 건강 관리 서비스** 제공 필요.  
- 운동 후 발생하는 불편 증상에 대한 **즉각 대처법 안내** 부재.  
- **신체 데이터(신장, 체중, 나이, 식습관)**를 고려한 **페이스 추천 서비스**가 없음.  
- 러닝 문화 확산과 함께 **러닝화 리셀·한정판 붐**이 일어나고 있으나,  
  구매 기회(래플/드로우 일정) 접근성이 낮음.  
- 한국적 정서에 맞춘 **기념일 기반 동기부여** 기능의 필요성.

---

## 🎯 연구 목표
- 사용자 맞춤 **러닝 가이드** 제공.  
- 불편 부위 입력 시 **스트레칭·회복 방법** 제시.  
- GPS 기반 **최적 러닝 코스 추천**.  
- **스마트워치 연동**으로 교수님이 제시한 *“하드웨어+서비스 결합”* 조건 충족.  
- **러닝화 발매 일정 캘린더 제공**으로 커뮤니티·수익화 요소 추가.  
- **한국 기념일 기반 러닝 챌린지**로 현지화된 동기부여 제공.  
- 단순 기록이 아닌, **헬스케어+커뮤니티+동기부여 중심 러닝 플랫폼** 개발.

## ⚙ 구현 방법
### 1. 데이터 입력/수집
- **기본 정보**: 신장, 체중, 나이, 성별, 식습관.  
- **실시간 정보**: GPS 이동 거리·속도, 심박수, 칼로리 소모, SpO₂, 걸음 수 (스마트워치 연동).  

### 2. 페이스 추천 알고리즘
- BMI, 연령, 과거 기록을 기반으로 **최적의 러닝 페이스 산출**.  

### 3. 코스 추천 시스템
- GPS 기반 주변 러닝 코스 탐색.  
- 거리, 경사도, 안전성, 공원 유무 고려.  

### 4. 운동 후 회복 관리
- 불편 부위 선택 → 해당 부위별 스트레칭·재활 가이드 제공.  
- 전문가(트레이너·물리치료) 자료 기반.  

### 5. UI/UX 설계
- **Before Running**: 맞춤 페이스 & 코스 추천.  
- **During Running**: 스마트워치 연동 → 실시간 데이터 모니터링.  
- **After Running**: 불편 부위 대응 + 건강 리포트.  

### 6. 러닝화 발매/래플 캘린더 기능
- **기능**: 나이키·아식스·해외 편집샵 등 러닝화 발매/래플 일정을 캘린더 형태로 제공.  
- **이유**: 러닝화 리셀 붐으로 인해 사용자들의 구매 욕구와 정보 접근성이 높음.  
- **부가효과**: 편집샵 광고·협업을 통한 **수익화 모델** 가능.  
- **기술**: 웹 크롤링/API 연동 → 앱 내 캘린더 표시 + 리다이렉션 링크.  

### 7. 한국 기념일 기반 러닝 챌린지
- **기능**: 삼일절, 광복절, 추석 등 한국 기념일 맞춤 러닝 챌린지 제공.  
- **이유**: 내수 시장 특화 → 현지 문화와 운동을 결합.  
- **방법**: 기념일 기간 러닝 목표 달성 시 특별 뱃지·칭호 지급.  
- **효과**: 동기부여 + 기념일 홍보 효과 + 앱 차별화.

## 🌟 기대효과
- **부상 예방** → 안전한 러닝 습관 형성.  
- **동기 부여** → 맞춤 서비스 + 기념일 챌린지로 지속성 강화.  
- **차별화** → 기존 러닝 앱 대비 헬스케어 + 커뮤니티 + 수익화 기능 강화.  
- **경제적 가치** → 러닝화 캘린더 제공을 통한 편집샵 광고·협업 수익 모델.  
- **확장성** → 웨어러블 연동 및 AI 분석으로 스마트 헬스케어 서비스 발전 기여.

## 📌 교수님 조건 충족 요약
- **하드웨어**: 스마트워치 → 심박수, 칼로리, GPS 등 실시간 데이터 수집.  
- **서비스**: 페이스 추천, 코스 안내, 스트레칭·회복, 러닝화 캘린더, 기념일 기반 챌린지 제공.  
- 따라서, **헬스케어 + 하드웨어 + 커뮤니티 서비스**가 결합된 **종합형 캡스톤 프로젝트**로서 타당성 확보.
