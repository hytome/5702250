## ch03 프로세스공부.
process.
프로세스란 현재 실행중인 프로그램 실행은 순차적으로 이루어져야한다.
구성요소:프로그램 코드 프로그램카운터(현재 실행중인 명령),레지스터 값. stack=임시데이터.
전역변수:data section.
heap:동적으로 할당된 메모리 영역.
프로그램:디스크에 저장된 정적인 실행파일.
프로세스:메모리에 적재되어 실행되는 활동적인 상태.
한 프로그램이 여러 프로세스가 될수 있다.
메모리 안에 프로세스.
stack
-함수 호출 정보
-지역변수
--
heap ->런타임중 동적 할당
data ->전역 변수 저장
text->프로그램 코드.
malloc으로 동적 할당하면 heap 을쓰고 그냥 함수를 실행하면 stack 을쓴다.
**** 
Process Control Block. pcb:프로세스를 추적/관리하기 위한 정보 묶음.
즉 프로세스의 신분증+이력서.
pcb에 포함되는 정보
process state=현재 상태.
program counter = 다음에 실행할 명령어의 주소.
cpu registers = 프로세스가 사용되는 레지스터 값들
cpu scheduling info = 우선순위,스케줄링 큐 포인터
memory management info = 메모리 영역정보(페이지 테이블 등)
Accounting info =cpu 사용시간 시작 시간등
I/O status info 할당된 I/O 장치,열려있는 파일등. 
A라는 프로세스가 실행되다 말고 멈췄으면 pcb가 정보를 보고 다시 이어서 실행가능.
****
프로세스 전환 순서:pcb0,1
save state from in pcb0 ->rerload state from pcb1 ->interrupt sysytem call >save state into pcn 1 ->reload state from pcb0.
****
저 과정이 context switch(문맥교환) 하나의 프로세스를 중지하고 다른 프로세스로 전환할때 일어나는 작업 .실제로 작업은 하지 않기때문에 오버헤드 발생 복잡할수록 전환 시간 길어짐.
****
threads=스레드, 하나의 프로세스는 하나의 실행흐름을 가졌으나 멀티 쓰레드 개념이 등장하면서 하나의 프로세스가 여러 실행 흐름을 가질수 있다.
멀티 쓰레드: 실행흐름, 하나의 프로세스 안에서 여러 스레드가 동시에 실행 가능.
스레드는 코드,데이터 힙메모리를 공유하지만 레지스터와 스택은 따로 따로임.
동시성 여러작업 병렬로 처리가능  자원 절약 새프로세스 만드는것보다 절약 응답성 향상 ui와 백그라운드 분리.이 장점.
****
운영체제는 여러 프로세스중에서 어떤것을 cpu에 할당할지 선택해야한다. 
이게 바로 프로세스 스케쥴링
종류 잡 큐=시스템 내의 모든 프로세스 
레디큐=메모리에 올라와있고 cpu기다리는 프로세스 
디바이스 큐=i/o를 기다리는 프로세스들  프로세스는 이 큐들 사이를 이동하면서 상태가 바뀜.
프로세스는 인풋 아웃풋 완료시 다시 레디큐로 들어옴 멀티프로그래밍 시스템에서 중요하다. 
****
운영체제는 세가지 스케쥴러가 존재한다.
숏-텀:cpu를 어떤 프로세스에 줄지 결정. 실행빈도 매우 높음,속도 매우중요.
롱-텀:어떤 프로세스를 레디큐로 보낼지 결정 실행빈도 낮음. 동시실행프로세스수 조절
i-o:인풋 아웃풋 작업은 많으나 cpu작업은 짧다. 파일읽기,네트워크 통신등등.
cpu-bound:계산이 많고 cpu점유시간이 김, 수치해석,암호화 계산.
미디어-텀:메모리 사용량이 너무 많을때 개입하는 스캐줄러.
스와핑을 한다: 일부프로세스를 메모리에서 디스크로,그리고 다시 메모리로.
****
Context switch=cpu가 한프로세스에서 다른 프로세스로 전환할떄 발생한다. 
현재 프로세스 상태를 pcb에 저장하고 새로운 프로세스의 pcb를 읽어와 상태복원. cpu가 새 프로세스 실행시작. 실제작업 수행되지않아서 낭비시간 발생. 상태만 복원하고 저장하기 때문에.
****
프로세스가 다른 프로세스 생성->부모 자식 관계. 
****
프로세스 종료:마지막 명령을 시행후 종료 exit()시스템 호출->자식프로세스는 종료하면서 운영체제에 자신의 상태값 반환 부모 프로세스는 wait()시스템 호출로 자식이 종료된걸 확인. 자원할당을 해제.
부모가 자식 강제종료:abort().
강제종료예시:할당된 자원 초과 사용 더이상 작입 필요 x 부모가 종료될 예정이면 자식 독립실행 x
****
좀비:자식은 종료되었지만 부모가 남음. 고아:부모가 먼저 종료되었지만 자식이 남아있음.
****
interprocess 커뮤니케이션 ipc 프로세스간 통신. 서로 협력하는 프로세스끼리 데이터 공유 동기화. 정보공유ㅡ,연산속도 모듈화,편의성을 위해서. 
두가지 모델:공유 메모리, 메세지 전달. shared Memory,message passing.
메세지 큐가 있으면 메세지 패싱 각프로세스가 메시지를 보내고 받으며 운영체제가 관리
메모리를 공유하면 쉐어드 메모리. 공통메모리 영역을 만들고 직접읽고 씀 운영체제가 메모리만 할당
메세지패싱:느림,단순,소켓,파이프. 운영체제를 통해 메세지를 주고받는 통신방식.
쉐어드메모리:빠름(직접접근),동기화필요(복잡),shm,mmap. 여러 프로세스가 하나의 메모리 공간 공유유
