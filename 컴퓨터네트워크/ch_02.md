## ch_02 network security
네트워크 시큐리티.
네트워크 보안의 분야.
인터넷은 원래 보안을 많이 고려하지 않고 설계되었다.
서로를 신뢰하는 사용자들이 투명한  네트워크에 연결되었기 때문.
그래서 인터넷 프로토콜 설계자들은 보안측면을 지금도 catch-up중이다.
모든 계층 layer에서 보안 고려가 필요하다.
****
멀웨어 Malware.
바이러스:특정 객체를 수신 실행 함으로써 스스로 복제되어 감염된다. 이메일이나 이런것
worm:객체 수신만으로 스스로 실행되어 수동적으로 복제되는 감염.
spyware:키 입력 방문웹사이트등을 기록하고 이를 수집 서버에 업로드.즉 동의 없이 몰래 정보수집.
감염된 호스트는 봇넷에 편입되어 스팸 발송 또는 ddos공격에 악용될수 있음
바이러스와 웜은 모두 자가 복제 하지만,바이러스는 실행해야한다. 웜은 수신만으로 자동 실행된다.
****
Denial of Service. Dos:서비스 거부 공격 공격자가 거짓 트래픽으로 서버나 대역폭을 과부화 시켜 정상 사용자에게 서비스 제공하지 못하게 함.
1.타겟 설정
2.네트워크내 여러 호스트를 침해.
3.침해된 호스트 들로부터 대상으로 대량 패킷 전송.
DoS:단일 출처 에서 공격
DDoS:여러 봇으로 분산공격.
****
packet sniffing. 패킷 스니핑. 가로채기
sniffing:네트워크를 통해 지나가는 패킷을 수집.
Promiscuous Mode:NIC가 목적지 주소를 무시하고 모든 패킷 수신.
WireShark:대표적인 GUI기반 패킷 캡처/분석도구.
****
Fake Identify:가짜 신분.
Ip spoofing:아이피 스푸핑은 공격자가 자신의 IP주소를 위조해서 패킷을 전송하는 기법입니다. 이를 통해 수신사는 패킷이 신뢰된 출발지로 부터 온것으로 오인하게 됩니다.

레이어링(Layering)
왜 필요할까? 복잡한 시스템을 다룰때
명시적 구조를 제공-> 복잡성 관리 식별과 관계를 용이하게 하기때문.
모듈화->유지 보수및 변경이 용이

인터넷 프로토콜 스택.
-application:네트워크 어플리케이션 지원. http,imap 이런것들.
-transport:프로세스간 데이터 통신. tcp,udp.
-network:출발지에서 목적지로 데이터그램 라우팅. ip,라우팅 프로토콜.
-link:인접 네트워크 요소간 데이터 전송. 이더넷 와이파이.
-physical:물리,케이블 위의 비트.
tcp/ip 스택은 5계층으로 되어있으며 각 계층은 고유역할 수행.
****
Encapsulation. 캡슐화.
각 계층이 자신만의 헤더를 붙이고 하위 계층으로 전달하여 계층별 역할을(주소지정,라우팅,오류검출) 등을 수행하게합니다.
이메일 전송시,어플리케이션 계층이 본문을 tcp헤더로 감싸고 ip헤더 이더넷 헤더를 차례로 덧붙여 전송하듯이 말이다.
